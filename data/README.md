# Dataset provenance and usage

**File required:** `melb_data.csv` (13,580 records; 21 original variables)

- **Name:** Melbourne Housing Snapshot
- **Kaggle dataset page:** https://www.kaggle.com/dansbecker/melbourne-housing-snapshot
- **Original underlying data:** Tony Pino, Melbourne housing-market data (as credited by the dataset publisher)
- **Snapshot:** September 2017; recorded sales January 2016-September 2017
- **Licence listed by Kaggle:** Creative Commons Attribution–NonCommercial–ShareAlike 4.0 (CC BY-NC-SA 4.0): https://creativecommons.org/licenses/by-nc-sa/4.0/
- **Redistribution:** Not included in the public-repository ZIP by default. Download directly from Kaggle to comply with the source licence and ensure provenance.

After downloading, place the file in this directory as `data/melb_data.csv`. The notebook also have `melb_data.csv` within the notebook itself.

Any future public redistribution of the CSV should preserve attribution, copyright/licence notices and applicable noncommercial/share-alike conditions. Treat licence compliance separately from licensing your own notebook code.
